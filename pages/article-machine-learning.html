Le Machine Learning : apprendre à partir d’exemples

Lecture : 5 min

Apprendre sans être programmé

Un programme classique suit des règles écrites à la main : « si l’e-mail contient tel mot, c’est un spam ». Le problème, c’est qu’il est impossible de prévoir toutes les règles. Le Machine Learning (apprentissage automatique) prend le problème à l’envers : on montre à l’algorithme des milliers d’exemples, et il en déduit lui-même les régularités.

Une fois entraîné, le modèle obtenu peut traiter des cas qu’il n’a jamais vus : un nouvel e-mail, une nouvelle photo, un nouveau trajet.

À retenir

  • Le Machine Learning apprend à partir de données, pas de règles écrites.
  • Supervisé : des exemples étiquetés. Non supervisé : des regroupements.
  • La qualité des données compte autant que l’algorithme.

Supervisé ou non supervisé ?

Quand chaque exemple est accompagné de la bonne réponse (« spam » ou « pas spam », « chat » ou « chien »), on parle d’apprentissage supervisé : l’algorithme apprend à reproduire ces réponses.

Quand les données n’ont pas d’étiquette, l’algorithme cherche lui-même des points communs et forme des groupes : c’est l’apprentissage non supervisé, ou clustering. L’algorithme k-means, que vous pouvez manipuler dans le labo, en est l’exemple le plus connu.

Des données avant tout

Un modèle ne peut pas être meilleur que les exemples qu’on lui donne. Si les données d’entraînement sont incomplètes ou déséquilibrées, le modèle reproduira ces défauts. C’est pourquoi une grande partie du travail en Machine Learning consiste à collecter, nettoyer et vérifier les données.
