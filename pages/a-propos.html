À propos du projet

NeuroLab est un site de vulgarisation réalisé en HTML5, CSS3 et JavaScript natif, dans le cadre du module TI504N à l’EFREI Paris.

L’équipe

Qui a fait quoi ?

Technologies et méthode

  • HTML5
  • CSS3 · Flexbox & Grid
  • Media queries
  • JavaScript ES6
  • Git & GitHub
  • Figma
  • Validateur W3C

Maquette conçue sur Figma, une branche Git par fonctionnalité, chaque pull request relue par un autre membre, et validation W3C de chaque page avant fusion. Aucune bibliothèque ni framework : tout le code est écrit à la main.
